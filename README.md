# Чек-лист офиса · RemGruz #1

PWA-приложение еженедельной проверки офиса для мастеров-приёмщиков. Тёмный интерфейс-«кокпит», 49 позиций, 7 разделов: Кухня №1 и №2, Туалет №1 и №2, Канцелярия, Бонусы клиентам, Хозблок.

**Регламент:** каждый понедельник утром, заявка — сразу после проверки. **Правило двух недель:** хватает на 2 недели — «Хватает», не хватает — количество и «Заказать».

## Четыре вкладки

- **Обход** — основной режим: позиции по одной, вопрос «Хватит на 2 недели?», две большие кнопки, автопереход к следующей непроверенной, свайпы, «Пропустить». Полоса в шапке — 7 сегментов-разделов: заполнение = проверено, зелёный/красный по статусу, оранжевая подсветка — текущий.
- **Список** — все 49 позиций по 7 разделам: обзор, отметки, степперы, чипы-якоря со счётчиками.
- **Заявка** — итог в виде термочека + отправка в два шага строго по порядку: Шаг 1 — письмо на **zakupki@remgruz1.ru** (готовое, из приложения), Шаг 2 — журнал закупок Google Sheets (строки помечаются «Офис»). После обоих шагов — зелёная плашка «Новая неделя» (сброс). XLS/CSV и печать — по необходимости.
- **История** — список отправок с устройства: фамилия, дата и время, способ (почта/журнал), число позиций. Не стирается при сбросе недели (ключ `rgo1_hist`).

Дата и «Кто проверяет?» (ФИО) попадают в заявку, журнал и файлы. Отметки — в localStorage (ключ `rgo1`), устройства между собой не синхронизируются.

## Файлы

`index.html` — всё приложение (данные + логика + стили). `manifest.json`, `sw.js`, `icons/` — установка на телефон (SW отключён в index.html — обновления доходят мгновенно).

## Как редактировать список

Правки — в «Чек лист офис структура — АКТУАЛЬНАЯ.xlsx» (лист «Офис»), затем в чат Еве: «Обнови приложение офиса по этому файлу». Колонку ID не трогать, у новых строк ID пустой.

## Установка

iPhone Safari → «Поделиться» → «На экран "Домой"». Android Chrome → ⋮ → «Добавить на главный экран». ПК Chrome → значок установки в адресной строке.
